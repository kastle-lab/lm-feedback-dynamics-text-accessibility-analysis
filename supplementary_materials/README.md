# Supplementary Materials

This directory contains supplementary materials that document definitions, derivations, and sample-size details for the human and LM-human agreement analyses. Each supplement is reproducible from the repository artifacts listed below.

Supplement  | Contents
--- | ---
[`S1_consensus_definition.md`](S1_consensus_definition.md)  | Defines human consensus, inter-rater agreement, and LM-human agreement metrics.
[`S2_lm_slm_agreement.md`](S2_lm_slm_agreement.md)  | Derives the LLM and SLM agreement means.
[`S3_sample_sizes.md`](S3_sample_sizes.md)  | Reports the analysis sample sizes and denominator choices.

## Source Artifacts

- Human annotation workbooks: `results/human_annotations/human_annotation_split_*.xlsx`
- Human inter-rater agreement workbook: `analysis/inter_rater_agreement_updated_completed_annotations.xlsx`
- LM-human agreement workbook: `analysis/llm_human_agreement.xlsx`
- Human inter-rater script: `scripts/analyze_inter_rater_agreement.py`
- LM-human agreement script: `scripts/analyze_llm_human_agreement.py`
