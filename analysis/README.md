# Analysis

This directory contains generated summary artifacts from the rewriting, judging, and annotation-analysis workflow.

## Directory Structure

Path  | Contents
--- | ---
`descriptive_statistics.csv`  | Summary statistics for the experiment outputs.
`deep_failure_analysis.csv`  | Aggregate failure-analysis summary across result logs.
`deep_failure_analysis_iteration.csv`  | Iteration-level failure-analysis summary.
`inter_rater_agreement_completed_annotations.xlsx`  | Inter-rater agreement workbook for completed annotations.
`inter_rater_agreement_updated_completed_annotations.xlsx`  | Updated inter-rater agreement workbook.
`llm_human_agreement.xlsx`  | Workbook comparing LLM judge scores with human annotation scores.
`stats.ipynb`  | Notebook used for exploratory or statistical analysis.
